# Stimmenblätter

Eine Seite je Figur: Funktion, Signatur (messbar), Verlauf, Goldzeilen und Gegenbeispiele. Gelesen werden sie vor dem
Schreiben eines Segments (Plan 9.4) und für die Prüflinse „Stimme“. Die Zitate in Anführungszeichen mit Zeilen-ID prüft
`python3 tools/writing/motifs.py` gegen den echten Text; ändert sich eine Zeile oder verschwindet eine ID, schlägt
`check.sh` fehl.
